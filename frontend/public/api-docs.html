Tradersecho API

Stock attention, ready for your own tools.

Pre-launch documentation. API purchases and data access are disabled while upstream redistribution permissions are reviewed. Examples describe the prepared interface; they are not a live-access offer.

Membership and allowance

The API is a separate $5/month subscription requiring an active paid Premium or Founder membership. A free Premium trial does not qualify. Founder’s one-time payment does not include the recurring API charge.

  • 10,000 accepted requests per calendar month, resetting at 00:00 UTC on the first.
  • 10 requests per UTC clock minute, shared across the account.
  • Replacing a key does not reset usage.
  • No automatic overage charges. Requests above the allowance return HTTP 429.
  • Personal or internal use. No resale, public redistribution or service-level guarantee.

Connect after launch

  1. Open Plans and subscribe to the API add-on.
  2. Create a key in the API section of Plans. Copy it immediately; it is shown once.
  3. Keep it on your server or in your tool’s secret storage. Never put it in a public page, URL or shared spreadsheet.
  4. Send it in the Authorization header. Replace or revoke it from Plans.
curl "https://tradersecho.com/api/v1/snapshot?window=1" \
  -H "Authorization: Bearer YOUR_API_KEY"

GET /api/v1/snapshot

window: 1 (24 hours, default), 7 or 30 days. One request returns up to 20 ranked stocks and sector aggregates. Intraday, research text, X posts, PDFs and personal account data are excluded from this initial version.

Results use existing collected data and a shared 60-second cache. Calling the API never refreshes X or invokes AI. Update delays and collection gaps are the same as on the website. Check as_of and stale before using a result.

{
  "window_days": 1,
  "as_of": 0,
  "stale": true,
  "rankings": [],
  "sectors": []
}

The structure above is illustrative, not live market data. as_of is Unix time in seconds. Ranking entries contain rank, ticker, name, sector, mentions, change, heat. Sector entries contain sector, stocks, mentions, share. change is percentage mention growth and may be null; heat is the attention score, not a price forecast. share is percentage of measured mentions.

Errors and usage

StatusMeaning
401Missing, invalid or revoked API key.
403Membership or API subscription is inactive.
422Unsupported timeframe.
429Minute or monthly limit reached. Minute limits include Retry-After.
503API access is paused or not yet open.

Successful responses include X-RateLimit-Monthly-Remaining. Authenticated accepted requests consume allowance, including a request that subsequently encounters a server failure. Invalid keys and rejected requests do not. Cache responses in your tool and avoid polling faster than the data changes.
