Tradersecho API

Stock sentiment, ready for your own tools.

Pre-launch documentation. API purchases and data access are disabled while upstream redistribution permissions are reviewed. Examples describe the prepared interface; they are not a live-access offer.

Membership and allowance

The API is a separate $5/month subscription requiring an active paid Premium or Founder membership. A free Premium trial does not qualify. Founder’s one-time payment does not include the recurring API charge.

  • 10,000 accepted requests per calendar month, resetting at 00:00 UTC on the first.
  • 10 requests per UTC clock minute, shared across the account.
  • Replacing a key does not reset usage.
  • No automatic overage charges. Requests above the allowance return HTTP 429.
  • Personal or internal use. No resale, public redistribution or service-level guarantee.

Connect after launch

  1. Open Plans and subscribe to the API add-on.
  2. Create a key in the API section of Plans. Copy it immediately; it is shown once.
  3. Keep it on your server or in your tool’s secret storage. Never put it in a public page, URL or shared spreadsheet.
  4. Send it in the Authorization header. Replace or revoke it from Plans.
curl "https://tradersecho.com/api/v1/snapshot?window=1" \
  -H "Authorization: Bearer YOUR_API_KEY"

GET /api/v1/snapshot

window: 1 (24 hours, default), 7 or 30 days. Returns ticker-level aggregates of existing AI sentiment classifications for covered stocks, sorted alphabetically. No X post text, IDs, authors, links, quotations, mention rankings, broker summaries or PDFs are returned.

Uses up to the newest 5,000 collected posts within the rolling window and a five-minute per-instance cache. sample_limited indicates truncation. Only completed current AI analyses with matching stock context contribute. A ticker needs at least five classified posts; missing data is omitted, never reported as neutral. This is sentiment in our collected sample, not all of X.

{
  "window_days": 1,
  "as_of": 0,
  "sample_limited": false,
  "method": "contextual_ai_aggregate_v1",
  "sentiments": []
}

Illustrative structure, not live market data. Each entry contains ticker, sentiment, score, bullish_pct, bearish_pct, neutral_pct, mixed_pct, unclear_pct, analyzed_at. Percentages use all classified posts; rounding can make their sum differ from 100. Score is 100 x (bullish - bearish) / (all classifications except unclear), from -100 to +100, or null when all are unclear. A positive score is bullish; negative is bearish. A zero score with opposing directions or mixed classifications is mixed; otherwise neutral. No known classifications means unclear. as_of is calculation time; analyzed_at is the latest contributing AI analysis time, both Unix seconds. Neither promises live coverage.

API calls do not collect new posts or invoke AI. Removing raw posts does not itself settle upstream rights for commercial distribution of derived scores; activation remains pending that review.

Errors and usage

StatusMeaning
401Missing, invalid or revoked API key.
403Membership or API subscription is inactive.
422Unsupported timeframe.
429Minute or monthly limit reached. Minute limits include Retry-After.
503API access is paused or not yet open.

Successful responses include X-RateLimit-Monthly-Remaining. Authenticated accepted requests consume allowance, including a request that subsequently encounters a server failure. Invalid keys and rejected requests do not. Cache responses in your tool and avoid polling faster than the data changes.
